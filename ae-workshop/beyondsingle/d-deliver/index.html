Preparing your work for the screen array

Here’s what you’ll make. A folder holding one HD video for each screen, exported as H.265 and named so the array knows which screen each one goes on.

Why we’re doing this. The array plays your work with tableauX, which plays each file full screen on its own display and keeps them all in step. So you stay in HD from start to finish: there’s no wide file to make.

What you’ll come away with. How to export each screen, check the whole work in tableauX on your own computer, and hand it in.

Start with one 1920 × 1080 sequence or video for each screen. That might be the Screen sequences from Two or more screens, loops from the After Effects workshop, or HD videos you’ve made somewhere else.

D1 · Export from Premiere D2 · Or from After Effects D3 · Check it in tableauX Hand it in

Part 1Export each screen from Premiere

D1 · One file per screen 1 step

  1. D-01

    Select Screen 1 in the Project panel and choose File → Export → Media. Set Format to H.265 (HEVC) and Preset to Match Source – High Bitrate. Set File Name to your surname followed by the screen number, like Smith_1, and export. Do the same for each screen: Smith_2, Smith_3.

    Number the screens left to right. The number at the end of each name is the screen it plays on: _1 on the left, _3 on the right.
    Making two-screen work? Export _1 and _2 only. With no _3 file, the third screen stays black.
    Don’t pick an HDR preset. Some H.265 presets are HDR, and their colour looks wrong on the array. Stay with Match Source – High Bitrate.

Part 2Or export each screen from After Effects

If your screens are After Effects compositions, one per screen, export them through Media Encoder. The Render Queue can’t make H.265.

Using DaVinci Resolve? That works too. On the Deliver page, export each screen at 1920 × 1080 as H.265, named as in D-01.

D2 · One file per screen 1 step

  1. D-02

    Select your Screen 1 composition and choose Composition → Add to Adobe Media Encoder Queue. In Media Encoder, set Format to HEVC (H.265) and Preset to Match Source – High Bitrate, then click the Output File name and rename it Smith_1. Add your other screens the same way, then click the green Start Queue button.

Part 3Check it in tableauX

tableauX is the app that plays the array. It runs on any Mac, so you can see your whole work, every screen side by side, before you hand it in. For more of what it does, see the tableauX resource page.

D3 · Preview your work 3 steps

  1. D-03

    Put your files in one folder, named with your surname (Smith). Nothing else goes in it.

    Make every screen the same length. Each file loops on its own length. If one screen is shorter, the screens drift further out of step on every loop.
  2. D-04

    Download tableauX, unzip it and move it to Applications. The first time, macOS blocks it: open System Settings → Privacy & Security, scroll down and click Open Anyway. The tableauX page walks through this.

    Takes a while to open the first time? macOS checks a new app before it runs, which can take up to half a minute. Later launches are quick.
  3. D-05

    Choose Import work… and pick your folder. Set the Tableau line to 3 displays (or 2 for two-screen work), then click Preview. Your screens play side by side in one window. Esc closes it.

  4. ✓

    Check before you hand it in. Each video is on the right screen, left to right, and they start together. Let it loop a couple of times: they should still be in step.

Part 4Hand it in

D4 · Deliver 1 step

    Give the folder to me directly, or upload it to the drop box. The link is on Moodle and Discord. If your work has sound, tell me which screen’s file carries it.
